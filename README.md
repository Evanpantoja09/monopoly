# Monopoly Matemático — versión corregida

## Cambio de esta versión
- La partida puede iniciarse con un mínimo de 2 jugadores.
- La cantidad elegida al crear la sala (2, 3 o 4) se conserva como capacidad máxima.
- El botón «Iniciar partida» se habilita cuando hay al menos 2 jugadores conectados y no supera la capacidad de la sala.
- Se mantiene el resto del proyecto y sus archivos.

## Publicación
1. Descomprime el ZIP.
2. Copia los archivos del interior de `MonopolyMatematico_corregido` a la raíz del repositorio de GitHub, reemplazando los archivos existentes.
3. Haz commit y sincroniza los cambios.
4. Abre la página y fuerza una recarga completa con Ctrl + F5.

Las reglas de Firestore incluidas son las reglas que se habían compartido para esta versión. Si ya publicaste esas mismas reglas en Firebase, no necesitas volver a cambiarlas.
